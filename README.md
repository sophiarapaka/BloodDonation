# Blood Donation App

A **Blood Donation App** developed in **Android Studio** that helps connect blood donors and recipients through a simple, intuitive, and user-friendly mobile interface. The application aims to promote blood donation awareness while making it easier for users to register and find suitable donors.

## Features

* User registration and login
* Donor registration with blood group selection
* Search for donors by blood group
* Clean and intuitive Android UI
* Mobile-friendly interface built for Android devices

## Technologies Used

* Android Studio
* Java/Kotlin
* XML (UI Design)
* Firebase (if used)

## Project Structure

* `app/` – Main Android application module
* `java/` or `kotlin/` – Application source code
* `res/layout/` – XML layout files
* `res/drawable/` – Images and icons
* `AndroidManifest.xml` – App configuration

## Purpose

This project demonstrates Android app development skills by building a practical mobile application with user-friendly navigation, responsive layouts, and real-world functionality.
